# Licencias de Activos y Atribución — Ashfall Haven

Todos los activos de audio, gráficos generativos, fuentes tipográficas y paletas de color en **Ashfall Haven** han sido diseñados internamente mediante tecnologías nativas de la web (HTML5 Canvas, Web Audio API procedural, SVG inline) y fuentes de código abierto libres de regalías.

## 1. Tipografías
- **Outfit**: Diseñada por Rodrigo Fuenzalida, disponible bajo Licencia SIL Open Font License (OFL v1.1).
- **Inter**: Diseñada por Rasmus Andersson, disponible bajo Licencia SIL Open Font License (OFL v1.1).
- **JetBrains Mono**: Diseñada por JetBrains, disponible bajo Licencia Apache 2.0.

## 2. Audio Procedural
- Los efectos de audio (viento con ceniza, alarmas volcánicas, pasos, interacción de UI y advertencias sísmicas) se sintetizan en tiempo real mediante la **Web Audio API** del navegador sin archivos de audio pregrabados de terceros.

## 3. Arte y Renderizado
- Sprites y vistas 2.5D de los edificios del refugio, partículas de ceniza y mapa de expediciones se generan en tiempo de ejecución vía JavaScript y la API Canvas 2D (`CanvasRenderingContext2D`).
- No se utilizan marcas registradas, nombres de personajes ni marcas comerciales de *State of Decay* ni de Microsoft / Undead Labs.
- Arquitectura e IP 100% original con ambientación en los Andes ficticios.
